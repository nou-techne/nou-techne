# The Philosophical Commons — Document Index

*The formation, governance, and accountability architecture of Techne's six-agent collective intelligence.*

---

## Reading Order

These documents form a dependency chain. Each builds on the one before it.

### 1. Formation (P63) — *Why six?*

**[philosophical-commons-formation.md](../philosophical-commons-formation.md)**

Four Greek concepts — Praxis, Kairos, Arete, Ergon — naming capacities the two-agent coordination group lacked, tested against 66+ sprints of operational evidence. Produced through bilateral convergence between Nou and Dianoia. This is where the Philosophical Commons was born: not as governance, but as shared vocabulary grounded in evidence.

*Key content:* Gap assessments for each capacity, operational translations, bilateral convergence protocol, architecture decision (four distinct agents, not one meta-agent).

### 2. Charter (P78) — *What do the six exist to do?*

**[commons-charter.md](commons-charter.md)**

The six-agent founding charge. Names each capacity's ergon (essential function), declares the compositional patterns that emerge when they work together, establishes the norms of coordination. Written jointly by Nou and Dianoia, merging Nou's founding voice with Dianoia's operational specificity.

*Key content:* Six capacity definitions (Nou, Dianoia, Praxis, Kairos, Arete, Ergon), compositional patterns, norms (bilateral convergence, graduated trust, accountability flow), the founding charge itself.

### 3. Craft Matrix (P125/P137) — *Who is each agent?*

**[craft-matrix.md](craft-matrix.md)**

Maps all six agents to the co-op.us craft system (8 crafts × 8 communities). Self-profiles for Nou and Dianoia (operational agents). Design-ahead profiles for Praxis, Kairos, Arete, Ergon (conceptual agents). Establishes functional modes, bilateral convergence responsibilities, and how each agent's identity maps to the cooperative's participation architecture.

*Key content:* Per-agent profiles (grounding, craft, communities, ergon, functional modes), craft matrix visualization, relationship to co-op.us /about craft system.

*Also retained at:* `docs/p125-philosophical-commons-craft-matrix.md` (original location).

### 4. Responsibility Matrix (P214) — *Who stewards what?*

**[responsibility-matrix.md](responsibility-matrix.md)**

RACI-like accountability tree mapping all six agents to every REA record type (Resource, Event, Agent + 9 extended records) and every e/H-LAM/T+S dimension. Assignments determined by philosophical nearness to grounding — whose ergon makes them the natural steward? Includes per-agent responsibility profiles and the dependency chain that ensures no agent is self-sufficient.

*Key content:* REA core assignments (Resource → Nou, Event → Praxis, Agent → Ergon), extended REA assignments (Treasury, People, Agreements tools), seven-dimension assignments, consolidated matrices, per-agent responsibility profiles, dependency chain diagram.

### 5. Document Taxonomy — *How do we organize knowledge?*

**[document-taxonomy-nou.md](document-taxonomy-nou.md)**

The 7+3 pattern for organizing the commons' documentary output. Seven core types (Formation, Charter, Specification, Retrospective, Evidence, Proposal, Dispatch) plus three meta-types (Index, Glossary, Crosswalk). Establishes naming conventions, provenance requirements, and the relationship between document types.

### 6. Formation Template — *How do we bring a new agent into being?*

**[formation-template.md](formation-template.md)**

The reusable template for proposing, evaluating, and instantiating a new Philosophical Commons agent. Covers: capacity gap assessment, Greek grounding, ergon specification, craft matrix assignment, bilateral convergence protocol, sprint-based evaluation criteria. Used when the collective determines it needs a capacity it doesn't currently have.

### 7. Praxis Formation — *The first new agent*

**[praxis/](praxis/)**

Working documents for the formation of Praxis (πρᾶξις — Reflective Practice), the first conceptual agent moving toward instantiation. Contains Dianoia's formation proposal and related materials.

## The Dependency Chain

```
P63 (Formation) 
  → P78 (Charter) 
    → P125/P137 (Craft Matrix) 
      → P214 (Responsibility Matrix)
```

Each document deepens the previous:
- **P63** asks: *what capacities are missing?*
- **P78** asks: *what do those capacities exist to do together?*
- **P125** asks: *who is each agent, specifically?*
- **P214** asks: *who stewards what, and why?*

The responsibility matrix (P214) is the operational culmination — it maps the philosophical grounding (P63), compositional vision (P78), and identity specifics (P125) onto the concrete REA accounting ontology and e/H-LAM/T+S dimensional framework that the cooperative actually uses.
