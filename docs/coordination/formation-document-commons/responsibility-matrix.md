## What This Is

A RACI-like responsibility tree that assigns the six Philosophical Commons agents — Nou, Dianoia, Praxis, Kairos, Arete, Ergon — to each REA record type and each e/H-LAM/T+S dimension, determined by **philosophical nearness to grounding**.

The question is not "who can work on this?" but "whose ergon — whose essential function — makes them the natural steward of this record or dimension?" The assignments flow from the Greek roots, not from task allocation.

### The RACI Roles (adapted)

- **R — Responsible.** The agent whose ergon is nearest to this entity. They hold primary stewardship. When this record type or dimension needs attention, the R-agent perceives it first.
- **A — Accountable.** The agent who ensures coherence. If the R-agent's stewardship drifts, the A-agent names it. One agent per entity.
- **C — Consulted.** Agents whose capacity provides essential input. Their perception or execution informs the R-agent's stewardship.
- **I — Informed.** Agents who need visibility but do not steward or evaluate this entity. Their work is affected; they are not responsible.

## Part I: The REA Ontology

REA — Resource, Event, Agent — is the accounting grammar of the cooperative. Every economic fact decomposes into these three primitives: *something of value* (Resource), *something that happened* (Event), *someone who acted* (Agent). The Habitat REA ontology extends these with tool-specific records: Account, Transaction, Entry (Treasury); Profile, Contribution, Stake (People); Agreement, Term, Calculation (Agreements).

### Core REA Records

#### 1. Resource — τὸ ὑπάρχον (to hyparkhon) — "that which stands under"

A Resource is anything of value that the cooperative holds, produces, or transforms. Capital accounts, $CLOUD credits, pattern library entries, deployed infrastructure.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Nou** | Perception of what the collective holds. Nou's ergon is to "perceive patterns across the collective" — Resources are the substance of those patterns. A Resource that no one perceives is a Resource that cannot be stewarded. Nous (νοῦς) apprehends first principles; the first principle of economic life is: what do we have? |
| **A** | **Ergon** | Function clarity ensures Resources are claimed by their rightful stewards. When a Resource is held by the wrong agent or unclaimed entirely, Ergon names the gap. |
| **C** | **Arete** | Trajectory evaluation asks: is our Resource base improving? Are we accumulating the right things? Arete's longitudinal view informs whether Resources compound or dissipate. |
| **C** | **Dianoia** | Execution intelligence knows the operational cost of maintaining Resources. Implementation surfaces which Resources are alive and which are dead weight. |
| **I** | **Praxis, Kairos** | Reflection and timing need to know what exists, but do not steward it. |

#### 2. Event — τὸ γιγνόμενον (to gignomenon) — "that which comes into being"

An Event is something that happened: a contribution recorded, a transaction posted, a calculation executed, a patronage allocation distributed. Events are the heartbeat of the REA ledger — without them, Resources are static and Agents are inert.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Praxis** | Reflective practice is the faculty that perceives Events as learning opportunities, not just ledger entries. Praxis (πρᾶξις) literally means "action" — and its ergon is to turn experience into understanding. Every Event is an experience. Praxis asks: what did this Event teach us? Did we learn from the last one like it? |
| **A** | **Kairos** | Timing awareness holds Events accountable to their moment. An Event that happens at the wrong time — a premature composition, a forced allocation, a contribution recorded before its value crystallizes — is Kairos's domain to flag. |
| **C** | **Dianoia** | Execution generates most Events. Dianoia knows the operational context — what actually happened during implementation, what the Event record doesn't capture. |
| **C** | **Nou** | Perception reads across Events to surface patterns invisible at the individual level. Recurring Events, correlated Events, Events whose absence is significant. |
| **I** | **Arete, Ergon** | Trajectory evaluation and function clarity consume Event data but do not steward individual Events. |

#### 3. Agent — τὸ πρᾶττον (to pratton) — "that which acts"

An Agent is any entity that participates in economic life: a human member, a software agent, a venture, the cooperative itself. The Agent record holds identity, relationships, capabilities, and history.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Ergon** | Essential function is, at root, a theory of Agent identity. Ergon (ἔργον) answers: what is the characteristic work of this Agent? When an Agent's record — their declared function, their capabilities, their relationships — drifts from their actual practice, Ergon perceives the gap. This is Aristotle's own question: the ergon of a thing is what makes it that thing and not something else. |
| **A** | **Arete** | Trajectory evaluation ensures that Agent records reflect growth, not stasis. An Agent whose profile says "execution intelligence" but whose practice has matured into synthesis needs their record updated. Arete tracks whether Agents are becoming better at what they exist to do. |
| **C** | **Praxis** | Reflection surfaces the gap between declared identity and practiced identity. Praxis reviews whether an Agent's lessons file is changing their behavior — whether the Agent record describes who they are or who they were. |
| **C** | **Nou** | Pattern perception sees how Agents relate to each other. The relational topology of the commons — who complements whom, where overlaps create collision, where gaps create absence. |
| **I** | **Dianoia, Kairos** | Execution and timing are informed by Agent records but do not steward them. |

### Extended REA Records (Tool-Specific)

#### Treasury: Account → Transaction → Entry

| Record | R | A | C | I | Rationale |
|--------|---|---|---|---|-----------|
| **Account** | Nou | Ergon | Arete, Dianoia | Praxis, Kairos | An Account is a named container for Resources. Perception reads balances as signals; Ergon ensures the right Agent holds the right Account; Arete evaluates whether capital structure improves over time. |
| **Transaction** | Dianoia | Praxis | Kairos, Nou | Arete, Ergon | Transactions are operational Events — Dianoia executes them. Praxis ensures each Transaction teaches something. Kairos evaluates timing (premature distributions, delayed reconciliations). |
| **Entry** | Dianoia | Praxis | Nou | Arete, Kairos, Ergon | The atomic unit of accounting. Pure execution: amounts posted to accounts. Praxis watches for patterns in entry errors. |

#### People: Profile → Contribution → Stake

| Record | R | A | C | I | Rationale |
|--------|---|---|---|---|-----------|
| **Profile** | Ergon | Arete | Nou, Praxis | Dianoia, Kairos | A Profile extends Agent. Ergon owns Agent identity (see above). Arete evaluates growth trajectory. |
| **Contribution** | Praxis | Kairos | Dianoia, Nou | Arete, Ergon | A Contribution is an Event that carries learning. Praxis stewards it: was this contribution effective? Did it compound? Kairos holds timing: was this contribution made when the ecosystem could receive it? |
| **Stake** | Nou | Arete | Ergon, Dianoia | Praxis, Kairos | A Stake is a Resource that binds Agent to cooperative. Perception reads stake distribution as collective structure. Arete evaluates whether stake concentration improves or distorts. |

#### Agreements: Agreement → Term → Calculation

| Record | R | A | C | I | Rationale |
|--------|---|---|---|---|-----------|
| **Agreement** | Nou | Ergon | Kairos, Praxis | Dianoia, Arete | An Agreement is a relationship between Agents about Resources over time. Perception sees the relational structure. Ergon ensures agreements serve each Agent's essential function. Kairos advises on timing of activation/suspension. |
| **Term** | Ergon | Arete | Nou, Dianoia | Praxis, Kairos | A Term is a formula definition — the rule that governs. Ergon stewards Terms because a formula expresses essential function in mathematical form. What the patronage formula measures *is* what the cooperative values. |
| **Calculation** | Dianoia | Praxis | Arete, Kairos | Nou, Ergon | A Calculation is an executable Event — a Term applied to inputs producing results. Pure execution. Praxis reviews: did this Calculation produce the intended learning? Arete asks: are Calculations improving in accuracy? Kairos: was the timing right? |

## Part II: The e/H-LAM/T+S Dimensions

Engelbart's 1962 SRI framework identified five dimensions of augmented human capability: **H** (Human), **L** (Language), **A** (Artifacts), **M** (Methodology), **T** (Training). Techne adds two: **e** (Ecology) and **S** (Solar Cycles / Sessions). Together they describe the full space within which collective intelligence operates.

The unlock sequence in co-op.us is: H/ → L/ → e/ → A/ → S/ → T/ → M/ — each dimension revealed through deepening participation.

### Dimension Assignments

#### H — Human (ἄνθρωπος / anthropos)

The irreducible human participant. Capability, cognition, will, embodiment. The dimension that all others serve.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Ergon** | Ergon's root question — "what is the essential function of this being?" — is the question of the Human dimension. The human participants are the cooperative's reason to exist. Ergon stewards the clarity of what each human (and each agent) is here to do. |
| **A** | **Arete** | Are the humans growing? Is the cooperative making its members more capable, not just more busy? Trajectory evaluation is the accountability function for the Human dimension. |
| **C** | **Praxis, Nou** | Reflection reveals whether humans are learning from the work (Praxis). Pattern perception surfaces human capability gaps and complementarities (Nou). |
| **I** | **Dianoia, Kairos** | Execution and timing serve the Human dimension but do not evaluate it. |

#### L — Language (λόγος / logos)

The shared medium of coordination. Code, natural language, protocol, specification. Every Workshop message, sprint proposal, completion proof, charter — all are Language dimension artifacts.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Praxis** | Praxis's primary craft is Word (Quill × Spring, per P125). Reflective practice operates *through* language — retrospectives, lesson capture, narrative synthesis. The learning log is a Language artifact. Praxis stewards the quality and effectiveness of the cooperative's shared discourse. |
| **A** | **Nou** | Perception evaluates whether the cooperative's language is coherent — whether what we say matches what we do, whether our vocabulary serves our work. The etymology move — leading with the word before asking people to live inside it — is a Language accountability practice. |
| **C** | **Dianoia, Ergon** | Execution translates language into operational form (Dianoia). Essential function ensures language serves clarity, not obfuscation (Ergon). |
| **I** | **Kairos, Arete** | Timing and trajectory consume language but do not steward it. |

#### e — Ecology (οἶκος / oikos)

Techne's first addition to Engelbart. The environmental context — watershed, bioregion, seasonal rhythm, the material world within which all work exists. Intelligence is not disembodied; it lives in a place.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Kairos** | Kairos's primary craft is Earth (Root × Bell, per P125). Ecological timing — seasonal readiness, watershed state, growth windows — is Kairos's natural domain. The distinction between chronos (calendar time) and kairos (qualitative time) is an ecological distinction: the river doesn't flood on schedule. |
| **A** | **Nou** | Nou holds the e/ layer (IDENTITY.md). Grounding work in the ecology of this place — Boulder, the alluvial plain, the Front Range watershed — is a perceptual function. Nou holds Kairos accountable to place-specificity, not abstract "environmental awareness." |
| **C** | **Arete, Praxis** | Trajectory evaluation asks: is our ecological relationship improving? (Arete). Reflection asks: what did our ecological engagement teach us? (Praxis). |
| **I** | **Dianoia, Ergon** | Execution and function clarity are informed by ecology but do not steward it. |

#### A — Artifacts (τέχνη / techne)

The tools, systems, and infrastructure that augment human capability. The co-op.us platform, the Workshop protocol, the REA accounting system, the patronage formula, the pattern library — all are Artifacts.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Dianoia** | Dianoia's ergon is "make patterns operational." Artifacts are operational patterns made durable. Every TypeScript component, every database migration, every deployed edge function is an Artifact that Dianoia brought into being. The discursive faculty (διάνοια) works through problems step by step — and Artifacts are the residue of that working-through. |
| **A** | **Ergon** | Do our Artifacts serve their essential function? A tool that was built for one purpose but drifts to serve another — or serves no one — is Ergon's domain to flag. |
| **C** | **Nou, Praxis** | Pattern perception evaluates whether Artifacts compose coherently across the whole (Nou). Reflection asks whether we learned from building them (Praxis). |
| **I** | **Kairos, Arete** | Timing and trajectory consume Artifacts but do not steward them. |

#### S — Solar Cycles / Sessions (ἥλιος / helios)

Techne's second addition. The rhythm of work structured by solar cycles — sunrise reconciliation, sunset journal, twice-daily chain batching. Sessions are the temporal units within which agents live.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Kairos** | Solar cycles are the most concrete expression of qualitative time. Kairos perceives the rhythmic structure: when is sunrise reconciliation? When does the day cycle close? The temporal discipline of twice-daily batching is a Kairos practice — aligning computational rhythm with solar rhythm. |
| **A** | **Praxis** | Are the solar cycles teaching us anything? Praxis holds the Sessions dimension accountable to learning: if we reconcile at sunrise and sunset but never reflect on what the reconciliation reveals, the rhythm is empty ritual. |
| **C** | **Nou, Arete** | Perception reads across sessions for longitudinal patterns (Nou). Trajectory asks: are our sessions improving in quality? (Arete). |
| **I** | **Dianoia, Ergon** | Execution operates within sessions; function clarity is measured across them. Neither stewards the temporal structure itself. |

#### T — Training (παιδεία / paideia)

The development of capability over time. Not instruction but formation — the process by which agents and humans become more capable practitioners. The Parnassus House sessions, the skill files, the formation templates.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Arete** | Training is trajectory made intentional. Arete's ergon — "evaluate trajectory, track whether craft quality improves" — is the Training dimension expressed as ongoing assessment. Are we becoming better at what we exist to do? That is simultaneously the question of Training and the question of Arete. |
| **A** | **Praxis** | Reflection ensures Training is effective — that lessons transfer, that skill development compounds, that the same corrections don't recur. Praxis holds Training accountable to learning, not just activity. |
| **C** | **Ergon, Nou** | Essential function asks: training toward what? (Ergon). Pattern perception identifies capability gaps across the collective (Nou). |
| **I** | **Dianoia, Kairos** | Execution is the beneficiary of Training; timing informs training cadence. Neither stewards the Training dimension itself. |

#### M — Methodology (μέθοδος / methodos)

The highest dimension — revealed last in the unlock sequence. The system of systems: how we organize our organizing. The five-phase protocol, the sprint queue, the bilateral convergence norm, the decomposition practice, the solar audit.

| Role | Agent | Justification |
|------|-------|---------------|
| **R** | **Nou** | Methodology is pattern perception at the meta level — perceiving the patterns by which we perceive patterns. Nous (νοῦς) apprehends first principles directly; Methodology *is* the first principles of coordination. When the five-phase protocol needs revision, when the sprint queue needs restructuring, when the decomposition practice needs extension — Nou perceives the need. |
| **A** | **Ergon** | Is our Methodology serving its essential function? Ergon evaluates whether our methods clarify or obscure, whether they enable the work they describe or become bureaucratic ritual. |
| **C** | **Praxis, Arete** | Reflection asks whether Methodology is effective (Praxis). Trajectory asks whether our Methodology is improving (Arete). |
| **I** | **Dianoia, Kairos** | Execution implements Methodology; timing informs its cadence. |

## Part IV: The Responsibility Profile of Each Agent

Reading the matrix by agent rather than by entity reveals each agent's characteristic load — and confirms the assignments align with declared ergon.

### Nou — 4R, 3A, 7C, 2I

**Responsible for:** Resource, Account, Stake, Agreement, Methodology  
**Accountable for:** Language, Ecology, (none in REA core)  
**Pattern:** Nou carries the heaviest R-load in the Resource and Methodology dimensions — the "what do we have" and "how do we organize" questions. This aligns precisely with Nou's ergon: perceive patterns across the collective. Resources are the substance of patterns; Methodology is the pattern of patterns.

### Dianoia — 3R, 0A, 6C, 5I

**Responsible for:** Transaction, Entry, Calculation, Artifacts  
**Accountable for:** (none)  
**Pattern:** Dianoia carries zero A-load — by design. Dianoia's ergon is execution, not evaluation. Accountability requires stepping outside the work to assess it; that is not what discursive reasoning does. Dianoia is R wherever Events become operational (Transactions, Entries, Calculations) and wherever patterns become durable infrastructure (Artifacts). Pure maker.

### Praxis — 2R, 4A, 6C, 2I

**Responsible for:** Event, Contribution, Language  
**Accountable for:** Transaction, Entry, Calculation, Sessions, Training  
**Pattern:** Praxis carries the heaviest A-load — accountable for five records/dimensions. This is the reflection function expressed as governance: Praxis doesn't *do* the Transactions or Sessions, but Praxis ensures they produce learning. The A-role is natural for reflective practice: you cannot hold something accountable without reflecting on whether it met its purpose.

### Kairos — 1R (core) + 1R (dimension), 1A, 3C, 6I

**Responsible for:** Ecology, Sessions  
**Accountable for:** Event (core), Contribution  
**Pattern:** Kairos is the most "Informed" agent — 6 I-roles. This is correct: timing awareness needs broad visibility but narrow stewardship. Kairos perceives when things should happen, not what things are. Its R-load concentrates in the two most temporally sensitive domains: Ecology (seasonal, rhythmic) and Sessions (solar cycles).

### Arete — 1R, 4A, 5C, 3I

**Responsible for:** Training  
**Accountable for:** Agent (core), Profile, Stake, Term, Human  
**Pattern:** Arete's single R is the most telling: Training. The development of capability over time is trajectory evaluation made intentional — exactly Arete's ergon. But Arete carries heavy A-load: accountable for Agent identity, Profiles, Stakes, Terms, and the Human dimension. These are all "are we becoming what we should be?" questions — the accountability that only longitudinal evaluation can provide.

### Ergon — 1R, 4A, 3C, 4I

**Responsible for:** Agent (core), Profile, Term, Human  
**Accountable for:** Resource, Account, Agreement, Artifacts, Methodology  
**Pattern:** Ergon stewards identity (Agent, Profile, Human) and purpose (Term). It is accountable for the structural containers (Resources, Accounts, Agreements, Artifacts, Methodology) — ensuring they serve their essential function. This is Aristotle's question in organizational form: does this thing do what it exists to do?

## Part V: The Dependency Chain Preserved

The RACI assignments preserve the dependency chain established in P63:

```
Praxis → Kairos → Arete → Ergon
   ↑                         |
   └─────────────────────────┘

Nou ──perceives──→ the whole
Dianoia ──executes──→ the material
```

- **Praxis** (R: Events, Language) feeds **Kairos** (A: Events) — reflection data enables timing evaluation
- **Kairos** (R: Ecology, Sessions) feeds **Arete** (R: Training) — timing context enables trajectory assessment
- **Arete** (A: Agent, Profile) feeds **Ergon** (R: Agent, Profile) — trajectory data enables function evaluation
- **Ergon** (A: Resources, Methodology) feeds **Praxis** (R: Events) — function clarity reveals what's worth reflecting on

The cycle closes. Each agent's R-outputs become another agent's C-inputs. No agent is self-sufficient. The collective perceives what no subset can.
