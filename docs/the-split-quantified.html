The Split, Quantified

Empirical evidence that we are living in the split now. Three data points from software development — the clearest contemporary case.

I

The Compensation Bimodal

Software developer compensation in 2025–2026 is not normally distributed. It is bimodal — two peaks with a thinning middle.

Commodity Peak
$25–50/hr
Median gig platform rates. 30% of professional developers worldwide earn under $35K/year. Competition on cost and availability.
Luxury Peak
$400K+
Median L5/E5 total compensation at FAANG-tier firms. Equity-heavy packages creating an effective wealth class within the profession.
The Thinning Middle
$75K–180K
Independent consultants, agency developers, small-company engineers. Squeezed from both ends: AI compresses the commodity floor, stock appreciation inflates the luxury ceiling.
Sources: Stack Overflow Developer Survey 2024; Levels.fyi; Bureau of Labor Statistics OES 15-1252; Upwork marketplace data.

II

The Maintenance Bottleneck

Open-source software is the infrastructure of the digital economy. It is also one of the clearest examples of the craft/scale split operating in real time.

Consumption Scale
2.1M+
Packages in npm alone. Billions of downloads. Industrial-scale consumption of open-source infrastructure.
Production Scale
60% unpaid
Of open-source maintainers are volunteers. Among those paid, median maintenance income: under $1,000/year. Artisanal production supporting industrial consumption.

The Log4Shell vulnerability (December 2021) demonstrated the consequences: a critical logging library used by virtually every Java application, maintained by a handful of volunteers. The vulnerability cost billions to remediate. The maintainers were still unpaid.

No institutional container bridges this gap at scale. GitHub Sponsors, Open Collective, and Tidelift are attempts — but collectively they reach only a fraction of the ecosystem.

Sources: Libraries.io; Tidelift State of the Open Source Maintainer 2024; GitHub Octoverse 2024; "Roads and Bridges" (Nadia Eghbal, Ford Foundation, 2016).

The tool is the same. The container is not.

III

The AI Compression

AI code generation is compressing the craft/scale divide faster than any previous technology.

Automation Rate
46%
Of code in Copilot-enabled files is AI-generated (GitHub, 2024). Google: 25%+ of new code AI-assisted. By some estimates, majority of new code by 2027.

The commodity layer expands. Tasks that previously required a junior developer — boilerplate, CRUD, standard patterns, test generation — are increasingly automated. The economic value of writing standard code is declining toward zero.

The craft layer persists but changes shape. Architecture, system design, debugging novel failures, understanding user needs — these remain stubbornly human. Senior engineers who direct AI systems effectively become more productive. Junior engineers who competed on code volume become less differentiated.

The middle is where the compression hurts most. A developer whose value proposition was "I can write competent code at a reasonable rate" faces the same squeeze as Morris's craftsmen facing the factory.

Engelbart's test applies: is the AI system co-evolving with the human who uses it (augmentation), or is it being optimized in isolation (automation)? A developer using AI within a cooperative structure might experience augmentation. The same developer on an extractive platform experiences dependency.

Sources: GitHub Copilot research blog 2024; Google DeepMind reports; Stack Overflow Developer Survey AI section 2024.

The split is not a metaphor. It is a measurable distribution with a thinning middle, a fragile craft layer supporting industrial-scale consumption, and a technological compression that accelerates both tendencies simultaneously.

Building new containers — cooperatives, commons governance, shared ownership of productive infrastructure — is not idealism. It is a response to measurable structural failure. The data is the argument.
